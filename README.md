# Anant Interiors — WEB-01
Responsive one-page interior design site for Jaipur.

## Run locally
Open `index.html` in a browser.

## Before submitting
1. Replace the demo WhatsApp number with the verified client number if supplied.
2. Create a public GitHub repository and commit the files using your own GitHub account.
3. Deploy the repository to Netlify/Vercel/GitHub Pages.
4. Put the live URL in `live-url.txt`.
5. Upload the complete screenshots folder.
